# Song #1
### *What I Made:*
I made a song that **you** can listen to(and change if you want!). It is an original song, with sounds from drums, piano, and guitar. 
### *How I Made It:*
I worked on a platform called *Strudel* and wrote code in JavaScript. In the end, I pasted my code into a Github Repo so it would be easily accessible. This was my first time making music by writing code, so I used the *Strudel Docs* to learn how to make it. 
### *How to Listen to It:*
You can listen to it directly on *Strudel* itself at this demo link: [Try here!](https://tinyurl.com/2venvmus)
Simply open the link and hit the play button. This is where I coded it. It's very convenient, writing code and being able to hear the music made by the code by the click of a button. If you want, edit the code and see how the music changes!
